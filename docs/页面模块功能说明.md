# 电影推荐博客页面模块功能说明

## 1. 文档概述

本文档用于说明电影推荐博客中各个页面的组成模块、主要功能、访问权限及页面之间的关系。系统主要分为前台展示、用户账户、个性化推荐、推荐反馈、算法统计和 Django 管理后台六个部分。

## 2. 全站公共模块

### 2.1 顶部导航栏

- **网站名称**：点击“电影资料馆”返回首页。
- **每日一片**：定位到首页的今日电影推荐区域。
- **近期片讯**：定位到首页的电影榜单与资讯区域。
- **个性化推荐**：进入电影类型选择页面，开始推荐流程。
- **登录/注册**：游客状态下显示，用于进入账户系统。
- **我的推荐/退出**：用户登录后显示，用于查看个人推荐历史或退出账号。

### 2.2 消息提示模块

- 显示表单校验错误、反馈保存成功等系统消息。
- 用于向用户说明当前操作是否成功以及需要补充的内容。

## 3. 首页

- **访问地址**：`/`
- **访问权限**：游客和登录用户均可访问。

### 3.1 今日电影推荐

- 每天从电影库中展示一部推荐电影。
- 显示电影海报、中文名、原名、年份、类型、豆瓣评分、排名和剧情简介。
- 提供“阅读今日电影”入口，进入电影详情页。
- 提供“生成我的片单”入口，进入个性化推荐流程。

### 3.2 一周口碑榜

- 展示当前豆瓣一周口碑榜前 6 部电影。
- 显示电影排名、海报、名称、简介、豆瓣评分和评价人数。
- 支持跳转到对应的豆瓣电影页面查看详情。

### 3.3 豆瓣电影排行榜

- 展示同步后的豆瓣电影排行榜前 6 部电影。
- 显示电影排名、海报、片名、信息摘要、评分和评价人数。
- 支持跳转到豆瓣来源页面。

### 3.4 个性化推荐入口

- 介绍系统通过电影分类和 1-5 分偏好评分生成 Top20 推荐片单。
- 点击“开始推荐”进入电影类型选择页面。

## 4. 电影详情页

- **访问地址**：`/movies/<电影ID>/`
- **访问权限**：游客和登录用户均可访问。

### 4.1 电影基本信息

- 展示海报、电影名称、原名、年份、豆瓣排名、评分和电影类型。
- 展示剧情简介、导演、主演和国家或地区信息。

### 4.2 页面操作

- “用它启发我的推荐”：进入个性化推荐流程。
- “回到首页”：返回网站首页。

### 4.3 相关影片

- 根据当前电影信息展示相关电影。
- 显示相关电影名称、年份、豆瓣评分和简介。
- 点击电影卡片可进入对应电影详情页。

## 5. 片讯详情页

- **访问地址**：`/news/<片讯ID>/`
- **访问权限**：游客和登录用户均可访问。

### 5.1 片讯信息

- 展示电影名称、原名、上映或活动日期、片讯类型、电影类型和地区。
- 展示片讯重点内容与电影海报。

### 5.2 来源与返回操作

- 可跳转到预告片或资料来源页面。
- 可返回首页的近期片讯区域。

## 6. 用户账户页面

### 6.1 注册页面

- **访问地址**：`/accounts/register/`
- **访问权限**：游客可访问。
- 使用 Django 用户名和密码体系创建账号。
- 展示字段帮助信息和输入错误。
- 注册成功后自动登录，并跳转到首页。
- 已有账号的用户可跳转到登录页面。

### 6.2 登录页面

- **访问地址**：`/accounts/login/`
- **访问权限**：游客可访问。
- 用户输入用户名和密码登录。
- 登录后生成的推荐会话自动绑定当前用户。
- 当用户从受保护页面跳转到登录页时，登录后可返回原页面。
- 提供注册新账号入口。

### 6.3 退出功能

- **访问地址**：`/accounts/logout/`
- **访问权限**：登录用户。
- 通过顶部导航栏的“退出”按钮结束当前登录状态。
- 退出后返回首页。

## 7. 个性化推荐流程

系统采用“选择分类 → 偏好评分 → 推荐结果与反馈”三步流程。游客可以使用完整流程；登录用户的评分和推荐记录会保存到“我的推荐”。

### 7.1 第一步：选择电影类型

- **访问地址**：`/recommend/category/`
- **访问权限**：游客和登录用户均可访问。
- 提供以下 5 种推荐分类：
  - 悬疑犯罪
  - 爱情剧情
  - 喜剧动画
  - 科幻动作冒险
  - 历史战争传记
- 用户选择分类后，系统创建一次推荐会话。
- 登录用户的会话绑定用户账号；游客会话仅使用匿名 UUID 标识。

### 7.2 第二步：电影偏好评分

- **访问地址**：`/recommend/rate/<会话UUID>/`
- **访问权限**：持有会话地址的游客或用户均可访问。
- 根据用户选择的分类展示代表性电影评分表。
- 每部电影可选择 1-5 分，也可以留空。
- 用户至少需要评价 8 部电影才能提交。
- 提交后保存 `UserRating` 偏好评分，并调用推荐算法生成 Top20 电影。

### 7.3 第三步：推荐结果

- **访问地址**：`/recommend/result/<会话UUID>/`
- **访问权限**：持有会话地址的游客或用户均可访问。
- 按推荐排名展示 Top20 电影。
- 每项结果显示电影名称、年份、类型、豆瓣评分、推荐理由、算法得分和推荐名次。
- 提供重新测试和返回首页操作。

### 7.4 推荐反馈

- 每部推荐电影下方提供 1-5 分反馈控件。
- 用户可评价“这部推荐是否符合自己的口味”。
- 点击“保存推荐反馈”后，系统保存所有已填写的评分。
- 同一推荐结果只保留一条最新反馈，再次提交会更新原评分。
- 留空的反馈项不会删除之前已保存的反馈。
- 游客和登录用户均可提交反馈。

## 8. 我的推荐

### 8.1 推荐历史列表

- **访问地址**：`/accounts/recommendations/`
- **访问权限**：仅登录用户；游客访问时跳转到登录页。
- 按创建时间倒序展示当前用户的推荐会话。
- 每条记录显示推荐分类、创建时间、完成时间、评分数量和首条推荐预览。
- 点击“查看详情”进入对应推荐历史详情页。
- 用户只能查看自己的推荐记录。

### 8.2 推荐历史详情

- **访问地址**：`/accounts/recommendations/<会话UUID>/`
- **访问权限**：仅会话所属的登录用户。

#### 我的评分模块

- 展示用户在生成推荐前评价过的电影。
- 显示电影名称、年份、类型和用户给出的偏好分数。

#### 推荐结果与反馈模块

- 展示本次会话生成的完整推荐片单。
- 显示推荐理由、算法得分和推荐名次。
- 展示已保存的反馈状态。
- 用户可在历史详情页补充或修改每部推荐电影的反馈评分。

## 9. 推荐算法统计页面

- **访问地址**：`/analytics/recommendations/`
- **访问权限**：仅管理员或具有 `is_staff` 权限的用户；游客跳转登录页，普通用户返回 403。

### 9.1 核心指标卡

- **推荐结果总数**：系统已经生成的推荐电影总量。
- **反馈数**：用户已经提交反馈的推荐结果数量。
- **反馈覆盖率**：反馈数占推荐结果总数的比例。
- **平均反馈分**：所有反馈评分的平均值。
- **好评率**：评分大于等于 4 分的反馈占比。
- **差评率**：评分小于等于 2 分的反馈占比。

### 9.2 按推荐排名统计

- 将推荐结果划分为 `Top1`、`Top2-5`、`Top6-10` 和 `Top11-20`。
- 分别统计推荐数、反馈数、覆盖率、平均分、好评率和差评率。
- 用于判断排名靠前的推荐是否更符合用户偏好。

### 9.3 按算法版本统计

- 按 `algorithm_version` 对推荐结果分组。
- 对比不同算法版本的反馈数量、平均分和正负反馈比例。
- 用于后续算法升级和效果对照。

### 9.4 按推荐分类统计

- 按五种电影分类分别统计推荐效果。
- 用于判断算法在不同电影类型上的表现差异。

## 10. Django 管理后台

- **访问地址**：`/admin/`
- **访问权限**：管理员账号或具有后台权限的用户。
- 顶部提供中文和英文切换入口。

### 10.1 博客内容管理

- **豆瓣电影排行榜**：管理榜单电影、排名、评分、评价人数和启用状态。
- **豆瓣一周口碑电影**：管理一周口碑榜数据。
- **近期电影片讯**：管理上映资讯、地区、日期、类型、排序和启用状态。

### 10.2 电影库管理

- 管理电影名称、原名、年份、分类、豆瓣评分、排名等信息。
- 支持按分类和年份筛选。
- 支持按片名、原名和豆瓣 ID 搜索。

### 10.3 评分管理

- **评分表**：管理五种分类所使用的评分表及代表电影。
- **用户偏好评分**：查看用户在推荐前给电影提交的 1-5 分评分。
- **用户推荐会话**：查看会话 UUID、分类、所属用户、创建时间和完成时间。

### 10.4 推荐结果管理

- 查看每条推荐结果对应的用户、分类、电影、推荐得分、排名和算法版本。
- 支持按算法版本、推荐分类和用户筛选。
- 支持按电影名、推荐理由和用户名搜索。

### 10.5 推荐反馈三级目录

推荐反馈采用三级查看方式，便于管理员按类别和用户分析数据。

#### 第一级：反馈分类

- 展示五种推荐分类。
- 每个分类显示反馈数量、反馈用户数和平均反馈分。
- 点击分类进入该分类的反馈用户列表。

#### 第二级：反馈用户

- 展示在当前分类下提交过反馈的登录用户和游客。
- 显示每个用户的反馈数量和平均反馈分。
- 点击用户名进入该用户在当前分类下的反馈明细。

#### 第三级：反馈明细

- 展示用户反馈对应的电影名称、推荐排名、反馈评分、算法版本、推荐得分和更新时间。
- 可用于追踪具体用户对具体分类和电影推荐的评价。

### 10.6 用户与权限管理

- **用户**：创建、修改和管理普通用户、工作人员及超级管理员。
- **组**：通过权限组批量分配后台操作权限。
- 管理员可通过 `is_staff` 和具体模型权限控制后台访问范围。

## 11. 页面与数据关系

| 页面操作 | 保存的数据 | 主要用途 |
| --- | --- | --- |
| 用户注册 | Django 用户账号 | 登录、归档个人推荐记录 |
| 选择推荐分类 | `UserSession` | 标识一次推荐流程及所属用户 |
| 推荐前电影评分 | `UserRating` | 建立用户偏好并作为算法输入 |
| 生成推荐片单 | `RecommendationResult` | 保存推荐电影、排名、得分、理由和算法版本 |
| 推荐后反馈评分 | `RecommendationFeedback` | 衡量推荐结果是否符合用户口味 |
| 管理员统计 | 汇总推荐结果与反馈 | 评估覆盖率、满意度和算法效果 |

## 12. 访问权限汇总

| 页面 | 游客 | 登录用户 | 管理员 |
| --- | --- | --- | --- |
| 首页、电影详情、片讯详情 | 可访问 | 可访问 | 可访问 |
| 注册、登录 | 可访问 | 可访问 | 可访问 |
| 个性化推荐三步流程 | 可访问 | 可访问并归档 | 可访问并归档 |
| 推荐结果反馈 | 可提交 | 可提交并关联账号 | 可提交并关联账号 |
| 我的推荐 | 跳转登录 | 仅查看自己的数据 | 仅查看自己的数据 |
| 推荐算法统计 | 跳转登录 | 403 禁止访问 | 可访问 |
| Django 管理后台 | 不可访问 | 需要后台权限 | 可访问 |

## 13. 核心业务流程

```text
注册/登录（可选）
    ↓
选择五种电影分类之一
    ↓
对代表电影进行偏好评分（至少 8 部）
    ↓
系统生成 Top20 推荐结果
    ↓
用户对推荐电影提交 1-5 分反馈
    ↓
登录用户在“我的推荐”查看历史记录
    ↓
管理员在统计页和管理后台分析算法效果
```
